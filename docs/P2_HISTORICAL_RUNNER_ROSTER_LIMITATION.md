# Historical Runner Roster Limitation

The M06 matrix is `HISTORICAL_DEVELOPMENT_ROSTER`. Historical raw data does not establish each race's active T-15 scratch universe. Therefore the matrix must not be interpreted as proving T-15 roster equivalence.

Current prospective operation must rebuild field-composition-dependent values, including V1 F8 and P2_CLASS field strength, from the observed decision-time active runner universe. This limitation does not alter development-row retention or strict-prior historical rules.
