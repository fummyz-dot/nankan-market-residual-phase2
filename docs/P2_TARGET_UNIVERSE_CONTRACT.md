# P2 Primary Target Universe Contract

`P2_PRIMARY_RACE_UNIVERSE_V1` is `DEVELOPMENT_FROZEN`. It assigns every 2020-01-01 through 2026-07-31 South Kanto race exactly one of `PRIMARY_ELIGIBLE`, `PRIMARY_EXCLUDED`, or `SECONDARY_ONLY` using only pre-race identity, raw condition/name/type, and P2 class-rule fields.

Precedence is: explicit JRA exchange; newcomer; unresolved bare exchange; canonical/mixed class; high-level special/open; local exchange; age-conditioned ungraded; other special. C3-containing races are excluded, explicit A1–C2 races are eligible, and unprovable class-floor contexts are secondary-only. Local exchange is not itself an exclusion.

No outcome, starter status, odds, popularity, payout, Market, model score, or ROI may change this universe. Amendments require a new protocol version. It is not yet a final-holdout freeze.

This contract supersedes `P2_CLASS_CONTRACT_DRAFT` only for Primary race-universe status; the earlier artifact remains preserved.
